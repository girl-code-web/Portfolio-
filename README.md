# 🐾 Pet Paradise - Insurance Landing Page

A professional landing page design for a **Pet Insurance** agency. This project demonstrates my ability to translate a business concept into a clean, functional, and aesthetic user interface using pure code.

## 🚀 Key Highlights:
- **Custom Business Layout:** Designed specifically for a service-based agency with a focus on conversions.
- **Hero Section Design:** Includes an engaging headline, pricing details, and a clear Call-to-Action (CTA).
- **Modern Navigation:** A sleek header containing business links (Claims, FAQs, etc.) and a user authentication button.
- **Benefit Visualization:** Clear value propositions (No fees, Unlimited payouts) to build user trust.

## 🛠 Tech Stack:
- **HTML5:** Semantic structure for better SEO.
- **CSS3:** Custom styling, layout alignment, and professional typography.

## 📁 Project Structure:
- `index.html`: The core content and layout of the landing page.
- `style.css`: Custom design and responsive styling.
